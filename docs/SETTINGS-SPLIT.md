# جداسازیِ «تنظیماتِ اپ» از «پنلِ من» — نسخهٔ ۰٫۱۲٫۰

> **مسئله:** در نسخهٔ ۰٫۱۱ یک صفحهٔ «تنظیمات» هم‌زمان دو جنسِ متفاوت داشت؛ تبِ اولش
> هم هویتِ سرور/نسخه/نقش/حساب‌ها/زیرساخت بود و هم قفلِ خودِ اپ.
> **راه‌حل:** دو صفحهٔ مستقل با دو مسئولیت، دو نقطهٔ ورود، و یک قاعدهٔ روشن برای اینکه
> آینده هر قابلیتِ تازه کجا برود.

---

## ۱. قاعده (معیارِ تصمیم برای آینده)

| پرسش | اگر «بله» → **تنظیماتِ اپ** | اگر «بله» → **پنلِ من** |
|---|---|---|
| بدونِ حساب/شبکه هم معنا دارد؟ | ✅ (تم، زبان، اعلان) | ❌ |
| دربارهٔ *این دستگاه* است یا *آن سرور*؟ | دستگاه | سرور |
| تغییرش روی گوشی ذخیره می‌شود یا روی پنل؟ | گوشی (`SessionStore`) | پنل (API) |
| با عوض‌کردنِ حساب باید عوض شود؟ | نه | بله |

خلاصهٔ یک‌خطی: **«تنظیمات» برای این گوشی است، «پنلِ من» برای آن سرور.**

## ۲. نقشهٔ جابه‌جایی

| قبلاً | حالا |
|---|---|
| تنظیمات ← تبِ «اتصال و حساب‌ها» → آدرس/ادمین/نوعِ احراز | **پنلِ من** → کارتِ «پنلِ فعلی» |
| … نسخهٔ پنل، سازگاری با ۵٫۵٫۱، نقش و اسکوپ | **پنلِ من** |
| … بازکردن در مرورگر، تستِ اتصال، سوئیچ/افزودنِ حساب | **پنلِ من** |
| … کارتِ «زیرساختِ پنل» (هاست/کور/قالبِ کلاینت) | **پنلِ من** → «زیرساختِ پنل» |
| … قفلِ برنامه و مهلتِ قفل | تنظیمات ← تبِ تازهٔ **«قفلِ برنامه»** |
| … دکمهٔ خروج از حساب | فقط **ورقهٔ حساب** (`AccountSheet`) |
| تنظیمات ← ظاهر / اعلان‌ها و مانیتورینگ / پیشرفته | بدونِ تغییر |

**نقطهٔ ورودها**

- «پنلِ من» ← ورقهٔ حساب (چیپِ آواتار روی نوار پایین، هر جای اپ) ← ردیفِ **«مدیریتِ پنل»**.
- «تنظیماتِ اپ» ← همان ردیفِ «تنظیمات» در ورقهٔ حساب و آیکونِ چرخ‌دندهٔ سربرگِ صفحه‌ها.

## ۳. نتیجهٔ عملی

- تب‌های تنظیمات از «اتصال ← ظاهر ← اعلان‌ها ← پیشرفته» به **«ظاهر ← اعلان‌ها ← پیشرفته ← قفلِ برنامه»** تغییر کرد (`SettingsSection`).
- صفحهٔ «پنلِ من» (`ui/screens/PanelScreen.kt`) سربرگ + بدنهٔ اسکرول‌شونده دارد و بخشِ اتصال را از `SettingsSectionsAdvanced.kt` بازاستفاده می‌کند — هیچ کدِ نمایشیِ تکراری ساخته نشد.
- ترتیبِ دکمهٔ برگشتِ گوشی: `زیرساخت → پنلِ من → تنظیماتِ اپ → ورقهٔ حساب → داشبورد → خروج`.
- خروج از حساب، انقضای نشست (۴۰۱) و سوئیچِ حساب هر سه صفحه‌های وابسته به نشست را می‌بندند (وگرنه «پنلِ من» با `session = null` روی صفحه می‌ماند).

## ۴. چرا این ساختار و نه سوییچِ داخلی

یک صفحه با سوییچِ «اپ | پنل» دو سطحِ تب روی هم می‌گذاشت (سوییچ + تب) و روی گوشی شلوغ می‌شد؛ از طرفی «پنل» فقط سه قلم دارد و تب‌بندی نمی‌خواهد. مهم‌تر: صفحهٔ «پنلِ من» در فازِ بعد خانهٔ **تنظیماتِ عمومیِ پنل، کلیدهای API، نقش‌های ادمین و لاگِ نود** می‌شود؛ جدا بودنش یعنی آن اقلام تنظیماتِ اپ را یک‌بارِ دیگر شلوغ نمی‌کنند.

## ۵. کارهای باقی‌مانده

1. صفحهٔ «تنظیماتِ پنل» (بیش از `settings.general`) در «پنلِ من».
2. کلیدهای API و نقش‌های ادمین در همان صفحه.
3. اگر «پیشرفته» هنوز مبهم است: شکستنش به تب‌های «کاربران» و «داده‌ها» (فاکتور + پشتیبان).
